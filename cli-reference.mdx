## snare arm

One-command setup: initialize + plant canaries + test webhook. Defaults to precision mode (awsproc, ssh, k8s).

```bash
snare arm --webhook <url>
snare arm --webhook <url> --label prod-server
snare arm --select --webhook <url>     # interactive picker
snare arm --all --webhook <url>        # all 18 types
snare arm --dry-run
```

| Flag | Description |
|------|-------------|
| `--webhook <url>` | Webhook URL (Discord, Slack, Telegram, PagerDuty, Teams) |
| `--label <name>` | Prefix canary names (defaults to hostname) |
| `--select` | Interactive TUI to pick which canaries to arm |
| `--all` | Plant all 18 canary types including dotenv-based ones |
| `--dry-run` | Show what would be planted without writing anything |

### --select mode

Interactive checklist. Arrow keys or j/k to move, Space to toggle, Enter to confirm.

```
  Select canaries to arm  Space toggle · Enter confirm · q abort

  PRECISION
→ ✓ awsproc       ~/.aws/config (credential_process)
  ✓ ssh            ~/.ssh/config (ProxyCommand)
  ✓ k8s            ~/.kube/<name>.yaml (server URL)

  HIGH
  ○ aws            ~/.aws/credentials (endpoint_url)
  ...

  MEDIUM
  ○ openai         ~/.env (OPENAI_BASE_URL)
  ...
```

Shortcuts: `a` select all, `n` select none, `p` reset to precision defaults.

## snare disarm

Remove all canaries. Surgical — only removes bytes Snare wrote.

```bash
snare disarm
snare disarm --purge          # also removes ~/.snare/ config
snare disarm --dry-run        # preview what would be removed
snare disarm --force          # skip hash verification
```

## snare status

Show active canaries with last-seen timestamps.

```bash
snare status
```

## snare events

Fetch recent alert events from snare.sh.

```bash
snare events                  # per-event detail view
snare events --summary        # ASN/UA distribution across all canaries
```

`--summary` shows ASN distribution, SDK/user-agent breakdown, likely-AI-agent count, and per-canary hit counts. Useful for triaging a canary fire — confirms whether activity looks like a cloud-hosted agent vs scanner noise.

## snare test

Fire a test alert to verify your webhook works end-to-end.

```bash
snare test
```

Registers a test token with snare.sh first, then fires the callback. Proves the full pipeline: registration → callback → webhook delivery.

## snare doctor

Validate your configuration and canary health.

```bash
snare doctor
snare doctor --test    # also fires a live test alert
```

Checks: config file, callback server reachability, webhook, active canary count, canary file integrity.

## snare config

Show or update configuration.

```bash
snare config                          # show current config
snare config set webhook <url>        # update webhook URL
```

## snare rotate

Rotate your device secret. Use if `~/.snare/config.json` was exposed.

```bash
snare rotate
```

Generates a new 256-bit secret, updates snare.sh, and re-registers all active tokens.

## snare plant

Plant individual canary types.

```bash
snare plant --type awsproc
snare plant --type ssh --label jump-box
snare plant --all
```

| Flag | Description |
|------|-------------|
| `--type <type>` | Canary type: aws, awsproc, gcp, ssh, k8s, pypi, git, terraform, openai, anthropic, npm, mcp, github, stripe, huggingface, docker, azure, generic |
| `--label <name>` | Prefix canary names |
| `--all` | Plant all canary types |
| `--dry-run` | Preview without writing |

## snare teardown

Remove specific canaries.

```bash
snare teardown --token <id>
snare teardown --dry-run
snare teardown --force       # skip hash verification
```

## snare serve

Run a self-hosted callback server.

```bash
snare serve --dashboard-token $(openssl rand -hex 32)
snare serve --port 9090 --dashboard-token <token>
snare serve --tls-domain canary.yourcompany.com --dashboard-token <token>
```

| Flag | Description |
|------|-------------|
| `--dashboard-token <token>` | **Required.** Token to protect the dashboard (min 16 chars) |
| `--port <n>` | Listen port (default: 8080) |
| `--db <path>` | SQLite database path |
| `--tls-domain <domain>` | Enable Let's Encrypt HTTPS |
| `--webhook-url <url>` | Global fallback webhook URL |

`SNARE_DASHBOARD_TOKEN` env var is also accepted.

## snare scan

Check canary integrity on disk. Reports missing, modified, or orphaned canaries.

```bash
snare scan
```

## snare uninstall

Complete removal: disarm + remove config + remove binary.

```bash
snare uninstall
snare uninstall -y          # skip confirmation
snare uninstall --force     # force-remove even if files changed since planting
```
