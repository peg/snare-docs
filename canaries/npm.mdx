---
title: npm
description: Scoped registry redirect — fires on npm install of packages in the fake scope.
---

The `npm` canary adds a scoped registry to `~/.npmrc` pointing at Snare. Any `npm install` of a package under the fake scope fires the callback.

## What gets planted

```ini ~/.npmrc
@agent-01-internal:registry=https://snare.sh/c/agent-01-ce023046.../
//snare.sh/c/agent-01-ce023046.../:_authToken=npm_TKRBfVtq...
```

## Trigger conditions

- `npm install @agent-01-internal/<any-package>`
- An agent trying to install internal packages from the fake registry

## Reliability: Medium

Only fires if something specifically tries to install packages in the fake scope. Unlike the pypi canary, this doesn't fire on every npm install — just scoped installs.
