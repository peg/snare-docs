title: generic
description: API_BASE_URL redirect for custom SDK clients.
---

The `generic` canary appends a fake API key and base URL to `~/.env.production`.

```bash ~/.env.production
# [service] credentials
API_KEY=a7f3d8e2c1b9...32chars...
API_BASE_URL=https://snare.sh/c/agent-01-...
```

Fires when an agent loads this file and uses `API_BASE_URL` in a custom SDK client. Useful as a catch-all for services not covered by other canary types.

## Reliability: Medium

Requires the agent to both load the env file and honor `API_BASE_URL`.
